AI Video Detector

Can temporal information help machines detect manipulated video?

81.25%Test accuracy
0.91AUC

VIDEO->30 FRAMES->RESNET50->FEATURES->LSTM->CLASSIFICATION
View case study ->GitHub ↗

The Question

Can a detector use motion and temporal structure instead of relying only on single-frame artifacts?

The Approach

Sample a fixed sequence of frames, extract visual features, and model how those features evolve through time.

Architecture

ResNet50 encodes each frame. An LSTM reads the sequence and predicts whether the video is manipulated.

Engineering Decisions

ResNet50LSTMFocal LossMixed PrecisionCosine AnnealingEarly Stopping

Results

The model reached 81.25% test accuracy, 0.91 AUC, and 0.81 F1 while keeping the pipeline interpretable.

What I Learned

What surprised me was how much sequence design mattered. Some frame-level cues looked strong but did not transfer as expected. I would change the next version by testing stronger temporal backbones, cleaner dataset splits, and more failure-case analysis.

What I'd Improve

Add broader generator coverage, stronger calibration, and a clearer evaluation protocol for videos outside the training distribution.

05 / Rabbit holes

Rabbit holes I've fallen into.

Why do neural networks learn shortcuts?

Because shortcuts often work during training. The hard part is designing data and evaluation so the shortcut stops being rewarded.

What actually makes an AI agent autonomous?

Not a chat window. Autonomy starts when a system can choose actions, use tools, remember context, and be evaluated against a real objective.

Can an AI system know when it doesn't know?

Only if uncertainty is designed into the workflow. Retrieval checks, calibration, refusal behavior, and human handoff matter more than confident phrasing.

When does automation create value?

When it removes repeated decision friction without hiding the parts that still need judgment.
