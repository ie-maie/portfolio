01 / Project

AI Privacy Forensic Auditor

How much does a trained model reveal about its training data?

Problem

Model privacy auditing with Membership Inference Attacks.

Approach

Modular forensic pipeline with preprocessing, feature encoding, PCA analysis, and reliability checks.

Tech Stack
Python / Scikit-learn / PCA / MIA
Key Details
  • 48,000+ census records processed
  • Reliability module using 95% confidence intervals
  • 10+ stratified runs for stability and uncertainty
Result

Built to analyze privacy leakage and model stability.
